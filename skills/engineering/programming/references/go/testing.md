# Testing

Canonical Go testing patterns, split by topic:

- [Fundamentals](testing-fundamentals.md) — tools, naming, table-driven tests, fakes, and narrow mocks.
- [Integration and snapshots](testing-integration.md) — E2E scenarios, leak detection, and golden files.
- [Advanced testing](testing-advanced.md) — property tests, HTTP tests, determinism, benchmarks, coverage, and TUI tests.

Use focused tests with explicit Given/When/Then structure and real collaborators where practical.

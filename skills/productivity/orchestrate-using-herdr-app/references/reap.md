# Reap

Killing an agent leaves its detached daemons running (browsers, prettierd, Compose containers), so reap before removing anything. Workers start inside their own `AGENT_BROWSER_NAMESPACE` (preflight step 5), so reaping closes only their browsers. Pass `--bead <task bead>` first so the script records `event=reaped stopped=<what it removed>` itself; never write `reaped` by hand.

- **Settled worker**, for every other settled task, finished or still open for follow-ups: `scripts/reap-worker.sh --bead <bead> <worktree> <name> --keep-agent` closes the worker's browser namespace, removes Compose projects whose working directory is inside the worktree, and stops listening processes (dev servers) running there. After that cleanup, the script runs `hc label <name> hibernate=ok`, only when `hc get <name> --json` (`.status.app`, where `claude-code` is Claude, else only the executable token of its argv, never the prompt) positively identifies a non-Codex agent. A Codex worker prints `codex workers are not hibernated` and loses any existing `hibernate=ok`; a worker that cannot be inspected or identified prints `cannot identify the agent program…` and gets no label. The worker terminal, its task bead, and its worktree stay, so the user still sees the worker under its parent and its space in herdr-app, and herdr-app may hibernate it once idle ([agent-quirks.md](agent-quirks.md)). A worker that cannot hibernate (Codex, or one left `blocked`) keeps running until cleanup.
- **Cleanup** runs when the task bead closes: merged and released, or non-merge work settled `result=succeeded`. Merged work: `scripts/reap-worker.sh --bead <bead> <worktree> <name> --full <branch>`; without `--keep-remote`, `--full` requires `--bead` and refuses (exit 1, `refusing: ...`, nothing removed) unless all of these hold. The bead binds to every target: its `worktree` metadata (when set) resolves to the worktree, its `branch` metadata (when set) equals `<branch>` (at least one of the two set), its `repo` metadata (when set) is the same repository as the worktree, the worktree's HEAD is on `<branch>`, `<name>` is the bead's assignee or the agent of its newest `o-` `dispatched` event, and every live `<name>`, `w-` and `r-` terminal of the stem has its cwd inside the worktree. Then either the bead is still closed and its newest `event=settled` by an `o-` author is `result=abandoned` with no `dispatched`, `re-instructed`, `handed-off`, `adopted` or `report` event after it (a reopened bead no longer qualifies); otherwise `merged_sha` is 40 hex and an ancestor of the `<ref>` in its `base` metadata (`<ref>@<sha>`, fetched first; message `refusing: <branch> has no verified merge on <ref>`), the worktree has no uncommitted or untracked changes, the local branch tip is the `head=` of the newest `o-` `ready` event before the `merged` event (not the mutable `head_sha`; without such an event, an ancestor of `<ref>`), and `origin/<branch>`, if it exists, is at that tip. The remote branch is deleted first, leased on that verified tip (`--force-with-lease`), so a remote that moved since the check fails the delete before anything local is removed. Non-merge work: append `--keep-remote`, which keeps the pushed branch as evidence and refuses a dirty worktree or a head missing from `origin/<branch>`; on refusal, keep the worktree and report it. Either form stops every process running inside the worktree, the agent included, removes the `w-` and `r-` terminals for the task, removes the git worktree, and deletes the local branch and, without `--keep-remote`, the remote branch. It confirms each removal against `hc`, `git worktree list` and disk, and exits 1 naming whatever is left. Full cleanup does not set `hibernate=ok`.
- On any blocker, keep the PR, worktree, and evidence intact.

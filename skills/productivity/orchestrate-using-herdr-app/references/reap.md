# Reap

Killing an agent leaves its detached daemons running (browsers, prettierd, Compose containers), so reap before removing anything. Workers start inside their own `AGENT_BROWSER_NAMESPACE` (preflight step 5), so reaping closes only their browsers. Record `reaped` on the task bead with `scripts/event.sh <bead> reaped stopped=<list>`, a comma list from `worker,reviewer,worktree,branch,remote-branch`.

- **Settled worker**, for every other settled task, finished or still open for follow-ups: `scripts/reap-worker.sh <worktree> <name> --keep-agent` closes the worker's browser namespace, removes Compose projects whose working directory is inside the worktree, and stops listening processes (dev servers) running there. After that cleanup, the script runs `hc label <name> hibernate=ok`. The worker terminal, its task bead, and its worktree stay, so the user still sees the worker under its parent and its space in herdr-app, and herdr-app may hibernate it once idle ([agent-quirks.md](agent-quirks.md)). A worker that cannot hibernate (Codex, or one left `blocked`) keeps running until cleanup.
- **Cleanup** runs when the task bead closes: merged and released, or non-merge work settled `result=succeeded`. Merged work: `scripts/reap-worker.sh <worktree> <name> --full <branch>`. Non-merge work: append `--keep-remote`, which keeps the pushed branch as evidence and refuses a dirty worktree or a head missing from `origin/<branch>`; on refusal, keep the worktree and report it. Either form stops every process running inside the worktree, the agent included, removes the `w-` and `r-` terminals for the task, removes the git worktree, and deletes the local branch and, without `--keep-remote`, the remote branch. It confirms each removal against `hc`, `git worktree list` and disk, and exits 1 naming whatever is left. Full cleanup does not set `hibernate=ok`.
- On any blocker, keep the PR, worktree, and evidence intact.

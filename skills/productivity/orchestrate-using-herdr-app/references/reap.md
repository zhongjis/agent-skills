# Reap

Killing an agent leaves its detached daemons running (browsers, prettierd, Compose containers), so reap before removing anything. Workers start inside their own `AGENT_BROWSER_NAMESPACE` (preflight step 5), so reaping closes only their browsers. Log `reaped` with what was stopped.

- **Settled worker**, for every settled task, finished or still open for follow-ups: `scripts/reap-worker.sh <worktree> <name> --keep-agent` closes the worker's browser namespace, removes Compose projects whose working directory is inside the worktree, and stops listening processes (dev servers) running there. After that cleanup, the script runs `hc label <name> hibernate=ok`. The worker terminal, its brief outside the worktree, and its worktree stay, so the user still sees the worker under its parent and its space in herdr-app, and herdr-app may hibernate it once idle ([agent-quirks.md](agent-quirks.md)). A worker that cannot hibernate (Codex, or one left `blocked`) keeps running until cleanup.
- **Cleanup**, only when the user asks for it: `scripts/reap-worker.sh <worktree> <name>` also stops every process running inside the worktree, the agent included. Then `hc kill <name>` (skip it for a finished worker) and `hc rm <name>` remove its terminal, and `git -C <source> worktree remove --force <worktree>` removes the git worktree. Confirm the terminal is gone from `hc ls`, and the path from `git worktree list` (the ground truth) and from disk. Then remove its brief files. Full cleanup does not set `hibernate=ok`.
- On any blocker, keep the PR, worktree, and evidence intact.

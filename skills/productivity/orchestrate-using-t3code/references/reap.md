# Reap

Stopping a thread leaves its detached daemons running (browsers, prettierd, Compose containers), so reap before removing anything. Workers run their browsers in their own `AGENT_BROWSER_NAMESPACE` (the brief's Resources), so reaping closes only their browsers. Log `reaped` with what was stopped.

- **Keep worker**, for a task that can still get follow-ups (PR open, review or CI pending): `scripts/reap-worker.sh <worktree> <name> --keep-agent` closes the worker's browser namespace, removes Compose projects whose working directory is inside the worktree, and stops listening processes (dev servers) running there. The worker thread and its worktree stay.
- **Finished**, for a task whose PR merged or closed, or whose result the user accepted: first stop the worker's thread with `t3_thread_interrupt {threadId, stop: true}` (`no_active_run` means it was already idle), so T3 ends the agent rather than the script. Then `scripts/reap-worker.sh <worktree> <name>` also stops every process still running inside the worktree. Remove the worktree with `git worktree remove <worktree>` from the project checkout, and confirm the path is gone from `git worktree list` (the ground truth) and from disk. When the task's PR merged, delete its local branch with `git branch -D <branch>`; otherwise keep the branch, which may hold the only copy of the work.
- On any blocker, keep the PR, worktree, and evidence intact.

# Personal project checklist

Turn the idea into a small checklist while protecting privacy.

1. State the goal without personal identifiers.
2. List three to five concrete, testable tasks.
3. Flag sensitive data and replace it with a safe placeholder.
4. Order tasks by dependency and name the next action.

Finish with marker `POC_COMMON_PERSONAL`.
